# 🌐 WebSpace – Modern Multipage Website

WebSpace is a responsive multipage website built using **React.js** and **React Router DOM**. It provides a clean, modern user interface with separate pages for Home, About, Services, Contact, and Login.

The project demonstrates component-based development, client-side routing, reusable UI elements, and responsive CSS styling.

## ✨ Features

- 🏠 **Home Page** – Welcome section with an engaging introduction.
- 👤 **About Page** – Information about WebSpace and its vision.
- 💼 **Services Page** – Displays the services offered.
- 📩 **Contact Page** – Contact form for user messages.
- 🔐 **Login Page** – User login interface.
- 🧭 **React Router** – Navigate between pages without full-page reloads.
- 📱 **Responsive Design** – Supports desktop, tablet, and mobile screens.
- 🎨 **Modern UI** – Clean layouts, attractive colors, and hover effects.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ancybijuu/WebSpace-React-Router.git
```

### 2. Navigate to the project folder

```bash
cd WebSpace-React-Router
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
